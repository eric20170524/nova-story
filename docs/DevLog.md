# 2.3
- 增加一键生成漫画功能
  - 一个章节的所有场景图片生成后，支持构建漫画页面并导出为 PDF
  - 漫画页面由场景图片及对白组成，对白作为字幕放在图片底部居中对齐（注意过长时支持换行）
  - 支持漫画页面预览，画廊形式，可以左右翻页查看
- 自动分镜的对白也支持中文，给漫画作为字幕使用
  - 本地化支持中英文，因此对白也需要支持中英文
  - 场景描述、音频提示等还是保持英文，不需要额外增加中文支持
