## 2. 后端工作流路由与选择机制

在 [`comfy_workflow_selection.ts`](file:///Users/lm/pyProj/nova-story/backend/src/services/comfy_workflow_selection.ts) 中，后端按以下优先级确定每次生图任务使用的 ComfyUI 工作流模板：

1. **项目级显式指定优先（`source: 'project'`）**：
   - 若项目设置 `project_settings.image_generation.workflow_id` 指定了数据库中的工作流 ID，则加载该工作流并通过 `inferComfyWorkflowFamily()` 校验其实际模型家族是否与 `project_settings.image_generation.model` 一致；若不一致则直接报错阻断，防止张冠李戴。
2. **按模型家族自动回退默认模板（`source: 'model'`）**：
   - 当未显式指定 `workflow_id` 时，按项目 `model` 字段映射默认工作流名称：
     - `pony` $\rightarrow$ [`pony_xl_12gb.json`](file:///Users/lm/pyProj/nova-story/backend/static/workflows/pony_xl_12gb.json)
     - `qwen_image` $\rightarrow$ [`qwen_image_2_1.json`](file:///Users/lm/pyProj/nova-story/backend/static/workflows/qwen_image_2_1.json)
     - `moss_image` $\rightarrow$ [`moss_image.json`](file:///Users/lm/pyProj/nova-story/backend/static/workflows/moss_image.json)
     - `redcraft_krea2` $\rightarrow$ [`redcraft_krea2_12gb.json`](file:///Users/lm/pyProj/nova-story/backend/static/workflows/redcraft_krea2_12gb.json)
     - `sd15` $\rightarrow$ [`sd15_draft_12gb.json`](file:///Users/lm/pyProj/nova-story/backend/static/workflows/sd15_draft_12gb.json)
3. **模型家族自动识别规则（`inferComfyWorkflowFamily`）**：
   - 包含 `UnetLoaderGGUF`、`CLIPTextEncodeFlux`、`DualCLIPLoader(type="flux")` 或 `flux` 权重名 $\rightarrow$ `flux`
   - 包含 `TextEncodeQwenImage21`、`CLIPLoader(type="qwen_image")` 或 `qwen_image` UNet 权重名 $\rightarrow$ `qwen_image`
   - 包含 `MOSSImageLayoutPrompt`、`UNETLoader` 匹配 `moss_image` 或 `CLIPLoader(type="moss_image")` $\rightarrow$ `moss_image`
   - 包含 `redcraft` / `krea` UNet 或 CLIP 权重/类型 $\rightarrow$ `redcraft_krea2`
   - `CheckpointLoaderSimple` 权重名匹配 `sd1.5 / anything / counterfeit / meina / chillout / sd15` $\rightarrow$ `sd15`
   - 其余 SDXL / Pony / Animagine / Illustrious 权重统一归入 $\rightarrow$ `pony`

## 3. 各工作流详细能力解析

### 3.1 Pony / SDXL 家族工作流（6 个）

#### (1) `pony_xl_12gb.json` —— 12GB 标准 Pony V6 XL 基线
- **文件位置**：[`backend/static/workflows/pony_xl_12gb.json`](file:///Users/lm/pyProj/nova-story/backend/static/workflows/pony_xl_12gb.json)
- **节点结构**：`CheckpointLoaderSimple` (Node 4) $\rightarrow$ `CLIPTextEncode` 正/负向 (Node 6/7) + `EmptyLatentImage` (Node 5) $\rightarrow$ `KSampler` (Node 3) $\rightarrow$ `VAEDecode` (Node 8) $\rightarrow$ `SaveImage` (Node 9，前缀 `NovaStory`)。
- **能力特点**：
  - 作为 `pony` 模型家族的默认兜底模板，结构最精简，适配 12GB 显存环境。
  - 原生正/负向提示词预置 `score_9, score_8_up, score_7_up, source_anime, cinematic shot` 与 `score_6, score_5, score_4` 质量门控；编译时 `preserveTemplateConditioning` 会保留模板质量头并与画风前缀/后缀、镜头描述智能合并（`mergeClipPositivePrompt`）。
  - 支持编译期动态注入 `LoraLoader`（同时连接 Model 与 CLIP）、Tier A `img2img`（动态插入 `LoadImage` $\rightarrow$ `ImageScale` $\rightarrow$ `VAEEncode`）、Tier B `IP-Adapter` / `FaceID Plus V2` 与 `ControlNet`，以及 Stage 2 面部局部裁切重绘。

#### (2) `pony_xl_baseline_l40.json` —— L40 算力卡 Pony V6 XL 基线（显式 CLIP Skip 2）
- **文件位置**：[`backend/static/workflows/pony_xl_baseline_l40.json`](file:///Users/lm/pyProj/nova-story/backend/static/workflows/pony_xl_baseline_l40.json)
- **节点结构**：在 `pony_xl_12gb.json` 基础上增加了 Node 10 `CLIPSetLastLayer`（`stop_at_clip_layer: -2`），正/负向 `CLIPTextEncode` 均从 Node 10 获取 CLIP 输出；输出前缀为 `NovaStory_PonyXL_L40`。
- **能力特点**：
  - 专为 Pony Diffusion V6 XL 最佳实践设计，强制在文本编码前截断倒数第二层 CLIP（Skip 2），避免未设 CLIP Skip 时出现语义过拟合或画风僵硬。
  - 其余动态 LoRA、Tier A `img2img`、Tier B 适配器注入能力与 `pony_xl_12gb.json` 完全一致。

#### (3) `pony_xl_tier_b_dual_ref_l40.json` —— L40 预置 Tier B 双参考（身份 + 姿态构图）工作流
- **文件位置**：[`backend/static/workflows/pony_xl_tier_b_dual_ref_l40.json`](file:///Users/lm/pyProj/nova-story/backend/static/workflows/pony_xl_tier_b_dual_ref_l40.json)
- **节点结构**：
  - 基础模型：`CheckpointLoaderSimple` (`ponyDiffusionV6XL_v6StartWithThisOne.safetensors`) + `CLIPSetLastLayer` (`-2`)。
  - **角色身份锁分支（Nodes 11–14）**：`LoadImage` (`character_ref.png`) + `IPAdapterModelLoader` (`ip-adapter-plus_sdxl_vit-h.safetensors`) + `CLIPVisionLoader` (`clip_vision_g.safetensors`) $\rightarrow$ `IPAdapterAdvanced`（`weight: 0.75`, `weight_type: "standard"`, `combine_embeds: "concat"`, `embeds_scaling: "V only"`, 作用区间 `0.0–1.0`）。
  - **构图/姿态控制分支（Nodes 15–17）**：`LoadImage` (`layout_ref.png`) + `ControlNetLoader` (`OpenPoseXL2.safetensors`) $\rightarrow$ `ControlNetApplyAdvanced`（`strength: 0.55`, `start_percent: 0`, `end_percent: 0.85`）。
  - **采样器（Node 3）**：`steps: 28`, `cfg: 7`, `euler_ancestral`, `normal`，接收 `IPAdapterAdvanced` 修正后的 Model 与 `ControlNetApplyAdvanced` 修正后的正/负向 Conditioning；输出前缀 `NovaStory_TierB_DualRef_L40`。
- **能力特点**：
  - 开箱即用的完整双参考图模板，无需依赖运行期动态拓扑构建即可验证或执行「角色外貌锁 + OpenPose 动作骨架锁」。
  - `end_percent: 0.85` 让最后 15% 采样步脱离骨架硬约束，保证衣物褶皱与边缘细节自然收敛。

#### (4) `autismmix_pony_l40.json` —— AutismMix SDXL 风格化动漫/插画工作流
- **文件位置**：[`backend/static/workflows/autismmix_pony_l40.json`](file:///Users/lm/pyProj/nova-story/backend/static/workflows/autismmix_pony_l40.json)
- **节点结构**：加载 `autismmixSDXL_autismmixPony.safetensors`，包含 Node 10 `CLIPSetLastLayer` (`-2`)；`KSampler` 采用 `steps: 28`, `cfg: 7`, `sampler_name: "dpmpp_2m"`, `scheduler: "karras"`；负向提示词默认排斥 `source_pony`；输出前缀 `NovaStory_AutismMix_L40`。
- **能力特点**：
  - 采用 `dpmpp_2m + karras` 采样组合，色彩浓郁、线条洗练，适合高表现力二次元与插画风格。
  - 在 [`generation_service.ts`](file:///Users/lm/pyProj/nova-story/backend/src/services/generation_service.ts) 中，当画风预设为 `autismmix_artist` 且生成分镜（`gen_type === 'scene'`）时，自动开启 `autismMixScene` 优化：将质量词前置（`qualityFirst: true`），并在负向提示词中自动追加 `western comic, thick ink outlines, comic strip, triptych, split screen, multiple panels, 3d render, photorealistic`，防止多格分屏或美漫粗黑线污染画面。

#### (5) `animagine_xl_4_l40.json` —— Animagine XL 4.0 纯正番剧工作流
- **文件位置**：[`backend/static/workflows/animagine_xl_4_l40.json`](file:///Users/lm/pyProj/nova-story/backend/static/workflows/animagine_xl_4_l40.json)
- **节点结构**：加载 `animagine-xl-4.0-opt.safetensors`；`KSampler` 采用 Animagine 官方推荐的低引导系数 `steps: 28`, `cfg: 5`, `euler_ancestral`, `normal`；正向词预置 `masterpiece, best quality, very aesthetic, newest, absurdres`；输出前缀 `NovaStory_AnimagineXL_L40`。
- **能力特点**：
  - 虽然归属于 `pony` (SDXL) 家族，但编译器通过 `isAnimagineXl` 专门识别 `animagine` 权重并执行专属适配：
    1. **剥离 Pony 专属质量词**：自动过滤掉 `score_9 / score_8_up / source_anime / rating_*` 等 Pony 词元，替换为 Animagine 4.0 原生质量词 `masterpiece, best quality, very aesthetic, newest, absurdres`。
    2. **过滤非兼容 LoRA**：自动剔除 Pony 风格/细节/NSFW LoRA，仅保留明确指定的角色 LoRA（`slot.role === 'character'`），防止 Pony 专用 LoRA 破坏 Animagine 权重分布。

#### (6) `illustrious_xl.json` —— Illustrious-XL 16:9 分镜工作流
- **文件位置**：[`backend/static/workflows/illustrious_xl.json`](file:///Users/lm/pyProj/nova-story/backend/static/workflows/illustrious_xl.json)
- **节点结构**：加载 `Illustrious-XL-v0.1.safetensors`；默认 `EmptyLatentImage` 即为 16:9 横屏（`1024×576`）；`KSampler` 为 `steps: 25`, `cfg: 7`, `euler_ancestral`, `normal`；输出前缀 `NovaStoryIllustriousXL`。
- **能力特点**：
  - 基于 Danbooru 新一代词库训练的 Illustrious-XL 底座，解剖结构与光影层次出色，且不带 `pony` 模板字符串（`preserveTemplateConditioning` 为 `false`），直接使用编译后的纯净提示词，适合 16:9 叙事分镜与 2.5D 风格扩展。

### 3.2 Qwen-Image、MOSS-Image 与 RedCraft Krea2 视觉语言与 DiT 工作流（3 个）

## 4. 编译器动态增强能力汇总（`compileComfyWorkflow`）

无论底层选用哪一个静态 JSON 模板，[`compileComfyWorkflow`](file:///Users/lm/pyProj/nova-story/backend/src/services/generation_service.ts) 在提交给 ComfyUI 前都会按任务上下文执行以下标准化编译：

1. **画布尺寸与任务类型自动适配（[`image_output_spec.ts`](file:///Users/lm/pyProj/nova-story/backend/src/services/image_output_spec.ts)）**：
   - **角色定妆照（`portrait`）与三视图单格（`turnaround` / `turnaround_panel`）**：固定采用 2:3 竖幅画布（SDXL / Qwen / MOSS-Image / Krea2 / FLUX 为 `768×1152`，SD1.5 为 `512×768`）。
   - **分镜关键帧（`scene`）与资产库底图（`location` / `prop`）**：默认遵循项目 `output_spec`（16:9 `standard` 下 SDXL / Qwen / MOSS-Image / Krea2 / FLUX 为 `1280×720`，`high` 为 `1536×864`，`draft` 为 `896×504`；ComfyUI 潜空间自动向 64 像素对齐，出图后由 `sharp` 归一化裁切回精确目标分辨率）。
2. **镜头级参考图智能门禁（[`character_reference_plates.ts`](file:///Users/lm/pyProj/nova-story/backend/src/services/character_reference_plates.ts) & [`reference_generation_policy.ts`](file:///Users/lm/pyProj/nova-story/backend/src/services/reference_generation_policy.ts)）**：
   - **单人近景/特写（`face` 槽）**：自动选取角色定妆照 `avatar_url`。支持 Tier A `img2img`（`denoise = 0.62`）或 Tier B `IP-Adapter`（权重 `0.60`，开启适配器时自动关闭 `img2img` 并将 `denoise` 置 `1.0`）。
   - **单人全身/中景（`body` 槽）**：自动选取三视图正面单人图 `turnaround_front_url`。禁用 `img2img`（防止把三视图的 A-pose 站姿硬拷进叙事镜头），仅通过 Tier B `IP-Adapter`（权重 `0.45`）或 Qwen-Image `image_1` 传递全身服装与体态身份。
   - **双人/多人、远景、建立镜头、俯瞰、打斗动作镜头（`none` 槽）**：对于非 `qwen_image` 模型，强制剥离单人参考图并关闭 `IP-Adapter`（`denoise = 1.0`），完全依靠文本外观锁与角色 LoRA，避免单人肖像参考图把双人/大场景压成单人大头照；对于 `qwen_image`，则走 `TextEncodeQwenImage21` 原生多图槽位（`image_1..image_6`）。
3. **NSFW / SFW 双向安全门控**：
   - 当有效 NSFW 模式开启时，自动叠加对应模型家族的成人/风格 LoRA，并调用 `stripSfwSuppressionFromNegative()` 清除负向提示词中残留的 SFW 屏蔽词（同时保留未成年安全排斥词 `CHILD_SAFETY_NEGATIVE`）。
   - 当有效 NSFW 模式关闭时，自动调用 `detachAdultLookLoras()` 卸载自定义工作流中预连的成人 LoRA（如 `ExpressiveH`、`Incase`、`aidma`），并在负向提示词中注入强 SFW 排斥项。
4. **纯女性镜头性别防漂移锁**：
   - 当 `isAllFemaleShot()` 判定当前镜头仅有女性角色时，自动向负向提示词追加 `FEMALE_ONLY_GENDER_DRIFT_NEGATIVE`（排斥 `1boy, 1man, male, masculine jawline, flat male chest` 等），防止特写或双女同框时发生性别漂移。
